# OpenWrt Telegram Admin Bot & Monitor

Интерактивный Telegram-бот для управления роутером на базе OpenWrt и система фонового мониторинга с уведомлениями в Telegram.

## Возможности

### 1. Telegram Бот (`router_admin_bot.sh`)
* **Интерактивное меню кнопок** в Telegram.
* **📊 Статус**: подробная сводка о роутере (Модель устройства, Версия OpenWrt, Uptime, CPU Load, Свободная ОЗУ и Flash-память, Активные сессии NAT, IP-адреса WAN/Внешний, состояние служб `Zapret`, `Podkop`, IP прокси-сервера и состояние прокси-соединения).
* **⚡ Пинг**: быстрая проверка доступности интернета (пинг до `8.8.8.8`) с выводом статистики задержки (`avg/min/max`).
* **📈 Нагрузка**: замеряет скорость приема и отдачи (в Mbps или Kbps) на внешнем интерфейсе WAN в реальном времени за 2 секунды.
* **📋 Логи**: отправляет последние 15 строк системного лога прямо в чат и прикрепляет файл с полным системным логом (`logread`).
* **🔎 DNS Тест**: проверяет корректность работы DNS-резолвера для прямого домена (`google.com`) и заблокированного ресурса (`youtube.com`).
* **🛣 Маршрут**: запускает трассировку пути до `8.8.8.8` (до 10 хопов) для поиска задержек на узлах сети.
* **🛡 Обход**: проверяет текущее число сессий NAT, правила маршрутизации (`ip rule`) и наборы таблиц `nftables` для обхода блокировок (`podkop`/`zapret`).
* **♻️ Перезагрузка**: безопасная перезагрузка роутера по кнопке.
* **Безопасность**: бот реагирует только на запросы от пользователей из белого списка (`ALLOWED_IDS`).

### 2. Фоновый Мониторинг (`router_telegram_monitor.sh`)
* Запускается по cron (каждые 5 минут) и отслеживает состояние связи и служб.
* **Интеллектуальные оповещения об интернете**: при отключении фиксирует время. При восстановлении соединения присылает детальную карточку с временем отключения, временем включения и общей длительностью простоя.
* **Мониторинг служб Zapret и Podkop**: присылает предупреждение при остановке служб и уведомление об успешном запуске после их восстановления.
* **Контроль прокси-канала**: проверяет, проходит ли трафик через прокси (socks/mixed inbound sing-box). Если прокси недоступен, но интернет работает, пришлет уведомление.
* **Защита от спама**: присылает оповещение строго один раз при падении и один раз при восстановлении (не спамит каждые 5 минут).

## Требования к роутеру

На роутере должны быть установлены пакеты `curl` и `jq`:
```bash
opkg update
opkg install curl jq
```

## Установка и настройка

### 1. Подготовка файлов
Склонируйте репозиторий или скачайте файлы. Откройте их в текстовом редакторе и настройте параметры:

* **В `router_admin_bot.sh` и `router_telegram_monitor.sh`**:
  * Замените `YOUR_TELEGRAM_BOT_TOKEN` на токен вашего Telegram-бота.
  * Замените `YOUR_TELEGRAM_CHAT_ID` на ваш числовой Telegram ID (или список ID через пробел).

### 2. Развертывание скриптов на роутере
Перенесите файлы на роутер (например, с помощью `scp`):
```bash
scp router_admin_bot.sh root@YOUR_ROUTER_IP:/etc/router_admin_bot.sh
scp router_telegram_monitor.sh root@YOUR_ROUTER_IP:/etc/router_telegram_monitor.sh
scp router_admin_bot.init root@YOUR_ROUTER_IP:/etc/init.d/router_admin_bot
```

### 3. Установка прав доступа и запуск автозагрузки
Подключитесь к роутеру по SSH и выполните команды:
```bash
# Делаем скрипты исполняемыми
chmod +x /etc/router_admin_bot.sh
chmod +x /etc/router_telegram_monitor.sh
chmod +x /etc/init.d/router_admin_bot

# Включаем и запускаем автозагрузку бота при старте системы (через procd)
/etc/init.d/router_admin_bot enable
/etc/init.d/router_admin_bot start
```

### 4. Настройка фонового мониторинга (Cron)
Откройте планировщик задач на роутере:
```bash
crontab -e
```
Добавьте следующую строчку для запуска проверки каждые 5 минут:
```text
*/5 * * * * /etc/router_telegram_monitor.sh
```
Сохраните изменения и перезапустите службу cron:
```bash
/etc/init.d/cron restart
```
